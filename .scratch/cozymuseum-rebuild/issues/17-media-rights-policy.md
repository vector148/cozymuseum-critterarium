# Issue 17 - Media rights and provenance policy

Status: complete

## Outcome

Adopt ADR-0007's zero-attribution media boundary for images, local copies, scientific text/data, and YouTube link/embed handling.

## Acceptance criteria

- [x] Policy separates source URLs, official embeds, and local copies.
- [x] The only accepted image classes are CC0 and Public Domain; every other class fails closed.
- [x] Local/Git-ignored files remain subject to rights checks.
- [x] YouTube is link/embed-only with no download or rehosting path.
- [x] Internal proof remains mandatory while visible creator attribution is unnecessary.
