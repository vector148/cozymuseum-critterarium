# CRO

Team01's single Performance Optimization mega-skill. Its master [SKILL.md](SKILL.md) routes `full-funnel-cro`, `commercial-analytics-attribution`, `commercial-content-audit`, and `brand-alignment-self-grill`; it verifies instrumentation and stage denominators, follows eligible cohorts beyond campaign-local metrics, pre-registers a hypothesis/primary metric/guardrails, and connects activation, retention, CAC, and LTV only when inputs are auditable before returning a versioned learning packet to Omnichannel Planning.
